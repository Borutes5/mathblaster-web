# MathBlaster v2 – web prototype (M1.1–M1.3)
Static site, no build step. three.js r170 vendored in vendor/ (MIT).
Run locally: `python3 -m http.server 8080` then open http://localhost:8080
Values mirror the Unity project (drag sensitivity 11, smoothing k=30, 8 shots/s, bullet 25 u/s, 1.5 s, x2 gate at x=1.75 z=12).
Play: https://borutes5.github.io/mathblaster-web/
